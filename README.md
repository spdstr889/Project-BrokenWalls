# BrokenWalls

An arrival guide for newcomers to Canada.

I built this because when I landed, nobody handed me a clear list of what to do next. You're tired, you have no internet, you don't know the banks, the carriers, or where to even start. This app fixes that.

---

## What it does

Walks you through the first things you need to do when you arrive in Canada, in order:

1. **Airport** — customs, kiosks, baggage, connecting flights
2. **SIM Card** — get internet before anything else
3. **SIN** — you need this for almost everything
4. **Bank Account** — what to bring, which banks, what to expect
5. **Getting settled** — food, community, religious places, local events

---

## Current version

Terminal based. Interactive checklist. Mark steps as complete, track your progress.

---

## Where this is going

- Web app with live carrier and bank comparisons
- Maps showing nearest offices, outlets, ATMs

- AI assistant that answers newcomer questions in plain language
